# sydney-housing-price-prediction
This project develops a machine learning model to predict residential property prices in selected Sydney suburbs. The project also includes a Streamlit application that allows users to enter property characteristics and receive a predicted sale price.

Files
housing_data.xlsx – Collected housing dataset used for the analysis and model development.
housing_analysis.ipynb – Jupyter Notebook containing data preparation, exploratory analysis, model development and evaluation.
app.py – Python source code for the deployed Streamlit housing price prediction application.
housing_price_model.pkl – Saved trained machine learning model used by the Streamlit application.
Application

The Streamlit application uses the trained machine learning model to generate estimated property sale prices based on user-provided property characteristics.
